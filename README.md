# MVP 01 - Análise Exploratória e Pré-processamento de Dados de Call Center

Projeto desenvolvido para a pós-graduação em Ciência de Dados e Analytics da PUC-Rio.

## Objetivo

Analisar os principais indicadores operacionais de uma central de atendimento, utilizando técnicas de análise exploratória, visualização e pré-processamento de dados.

## Dataset

Call Center Workforce Dataset (WFO, AHT, KPI), disponível no Kaggle, contendo 10.000 registros e 30 variáveis de dados simulados, sob a licença CC0.

## Ferramentas utilizadas

Python, Pandas, NumPy, Matplotlib, Seaborn e Google Colab.

## Como executar

[Acessar o notebook no Google Colab](https://colab.research.google.com/drive/1rwujowK2UtugB6dOcr2KkOGLylpy-29m)

A base de dados é carregada diretamente do GitHub. Para reproduzir o trabalho, basta executar todas as células do notebook.
